# 💍 Digital Wedding — Витрина Цифровых Пригласительных

Современный адаптивный одностраничный сайт-портфолио (Landing Page) для демонстрации, каталогизации и оформления индивидуальных заказов на свадебные цифровые пригласительные.
> 🌐 **Сайт работает по**  [ссылке](https://na1x-dev.github.io/WeddingCard/)
---

## ✨ Особенности платформы

* **Мультиязычный интерфейс (i18n):** Полноценная поддержка локализаций (RU / EN). Перевод всех текстовых узлов, кнопок и контента карточек выполняется динамически без перезагрузки страницы.
* **Умный прелоадер:** Минималистичный премиальный экран загрузки, скрывающий интерфейс до полного рендеринга шрифтов и фонового медиа-контента.
* **Интерактивный конструктор ссылок:** При клике на заказ любого шаблона система автоматически считывает его уникальный ID, переводит название на текущий язык пользователя и кодирует (URL Encode) готовое текстовое приветствие для мессенджеров.
* **Эффект Glassmorphism:** Современный журнальный стиль карточек шаблонов с использованием динамического размытия (`backdrop-filter`) и мягких CSS-трансформаций при наведении.

---

## 🛠 Технологический стек

* **Архитектура:** Vanilla JavaScript (Чистый ES6+ код, без использования сторонних фреймворков и библиотек).
* **Стилизация:** CSS3 (Custom Variables, Flexbox, Layout Grid, `@keyframes` анимации).
* **Типографика:** Google Fonts (Изящный сериф 'Forum' для заголовков и геометрический санс-сериф 'Montserrat' для контента).

## 📂 Структура корневого каталога

```text
├── source/               # Графические ресурсы (Favicon, фоновые изображения)
├── config.js             # Глобальный конфигурационный файл (База шаблонов, словари переводов)
├── index.html            # Главная страница (Разметка витрины и модальных окон)
├── script.js             # Архитектура i18n, рендеринг кнопок контактов, управление прелоадером
├── style.css             # Глобальная дизайн-система, адаптивная сетка и стили элементов
└── README.md             # Документация проекта
```

## ⚙️ Локальное развертывание и кастомизация

### Добавление новых макетов в каталог:
Для расширения ассортимента достаточно открыть корневой файл `config.js` и добавить новый объект в массив `templates`:

```javascript
{
  id: 2,
  style: "modern",
  image: "/source/pre_img/modern.png",
  demoUrl: "/modern_design/index.html",
  title: {
    ru: "Золотой Модерн",
    en: "Golden Modern"
  },
  description: {
    ru: "Геометрические линии и глубокие золотые акценты.",
    en: "Geometric lines and deep golden accents."
  }
}
```
Скрипт автоматически подтянет новые данные, создаст карточку в сетке и привяжет к ней правильные шаблоны отправки сообщений.
