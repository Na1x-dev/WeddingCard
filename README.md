# 💍 Свадебное приглашение

> 🌐 **Вы можете протестировать сайт по**  [ссылке](https://na1x-dev.github.io/WeddingCard/)

Современный, полностью адаптивный одностраничный сайт-приглашение (свадебный лендинг). Включает в себя интерактивную карту Yandex, динамический таймер обратного отсчета, интерактивное превью цветовой палитры дресс-кода и продвинутую RSVP-анкету с AJAX-отправкой данных на бэкенд Google Apps Script.

---

## 🌟 Особенности проекта

* **Централизованная конфигурация:** Все ключевые данные (имена, дата, таймлайн, палитра, ссылки на карты) вынесены в отдельный файл `config.js` для быстрой кастомизации.
* **Динамический дизайн и темы:** Гости могут интерактивно переключать цвета палитры дресс-кода (Песочный, Шампань, Оливковый, Голубой) с плавными CSS-переходами.
* **Стабильный таймер:** Кастомный счетчик времени, который автоматически рассчитывает остаток дней, часов, минут и секунд до торжества на основе установленной в конфиге даты.
* **Умная RSVP-форма:** 
  * Блок с дополнительными вопросами (алкоголь, меню) автоматически скрывается, если гость выбирает статус «Не смогу».
  * Реализовано умное взаимоисключение: выбор чекбокса «Не пью алкоголь» автоматически сбрасывает все остальные выбранные напитки.
  * Защита от спама и повторных кликов: кнопка отправки блокируется на время выполнения запроса, выводя статус синхронизации.
* **Двойной бэкенд (Sheets + Telegram):** Ответы мгновенно уходят в Google Таблицу и дублируются уведомлением в Telegram-чат. При повторном заполнении формы с тем же именем скрипт автоматически перезаписывает старую строку, избегая дублирования гостей в таблице.
* **Плавная адаптивность:** Интерфейс оптимизирован под любые устройства (мобильные телефоны, планшеты, десктопы). Кнопки RSVP и чекбоксы автоматически перестраиваются в одну колонку на экранах менее 600px.

## 🛠 Технологический стек

* **Frontend:** HTML5, CSS3 (Кастомные CSS-переменные, Flexbox, CSS Grid, `@keyframes`), Vanilla JS (Чистый JavaScript без тяжелых внешних библиотек).

## 🚀 Инструкция по развертыванию под себя

### 1. Подготовка Telegram-бота
1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте его **токен**.
2. Создайте группу (или канал), добавьте туда бота и получите **Chat ID** (например, через бота `@userinfobot`).

### 2. Настройка базы данных и бэкенда (Google Таблицы)
1. Создайте новую **Google Таблицу**.
2. Перейдите в верхнем меню: **Расширения** -> **Apps Script**.
3. Удалите стандартный код и вставьте JS-код веб-приложения (из вашего файла для Google Скриптов).
4. В самом верху скрипта заполните ваши данные бота:
   ```javascript
   const TG_TOKEN = "ВАШ_ТОКЕН_БОТА"; 
   const TG_CHAT_ID = "ВАШ_ID_ЧАТА"; 
   ```
5. Нажмите кнопку **Начало развертывания** (Deploy) -> **Новое развертывание**.
6. Выберите тип: **Веб-приложение** (Web app).
7. В поле *Кто имеет доступ* (Who has access) **обязательно** укажите **Все** (Anyone).
8. Скопируйте предоставленный **URL веб-приложения**.

### 3. Привязка данных в коде сайта
1. Откройте файл `config.js`.
2. Вставьте скопированный URL в константу `WEB_APP_URL`:
   ```javascript
   WEB_APP_URL: "ВАШ_URL_ВЕБ_ПРИЛОЖЕНИЯ"
   ```
3. Настройте вашу дату свадьбы в переменной `WEDDING_DATE`. 
   > *Обратите внимание: в JavaScript нумерация месяцев начинается с 0 (0 — январь, 8 — сентябрь)*.
4. При необходимости измените имена молодоженов, пункты программы (TIMELINE), палитру (PALETTE) или адрес проведения прямо в `config.js`.

### 4. Публикация на GitHub Pages
1. Загрузите файлы репозитория на свой аккаунт GitHub.
2. Перейдите в **Settings** -> **Pages** вашего репозитория.
3. В качестве источника (Source) выберите ветку `main` (или `master`) и нажмите **Save**.
4. Через пару минут сайт станет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
